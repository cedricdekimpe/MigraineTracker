# Security

Migraine Tracker holds health data, so a security report is welcome and taken seriously.

**Please report privately** to contact@migraine-tracker.eu (subject "Security"), or through GitHub's
"Report a vulnerability" button on this repository. Do not open a public issue for a vulnerability.

Useful in a report: what you found, how to reproduce it, and what it lets someone do. Please do not read, change or delete
data that is not yours, and do not run tests that degrade the service.

This is a one-person project: I will answer as soon as I can, and tell you when it is fixed. There is no bounty.
